# Bundled demo data

`demo_banking77.csv` is the Banking77 dataset (train and test files merged, whitespace collapsed):
13,083 customer-service queries labelled with 77 banking intents.

- Source: https://github.com/PolyAI-LDN/task-specific-datasets (`banking_data/`)
- Paper: Casanueva et al., "Efficient Intent Detection with Dual Sentence Encoders", NLP4ConvAI 2020
- Licence: Creative Commons Attribution 4.0 International (CC BY 4.0)

It is included only so `callswap demo` works offline. The rest of callswap is MIT licensed.
